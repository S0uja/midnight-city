# Midnight City V30 — Player Mode Prototype

- Kirill is now the player-controlled character.
- Alice remains autonomous and continues using the existing Brain/Utility/Memory systems.
- Added WASD / arrow movement on the 2D top-down map.
- Approaching Alice within a short distance pauses the simulation and opens an interaction menu.
- Added Talk, Eat Together, Walk Together, Date, Flirt, Hug, Kiss and non-explicit Intimacy actions.
- Player interactions update relationship, memory and journal through the existing relationship system.
- Added fast-forward controls: +1 hour, +6 hours, +1 day, +7 days, +30 days.
- Fast-forward temporarily runs the simulation and returns to the previous running/paused state.
- Added player position to the simulation state and API endpoints for movement/interactions/fast-forward.
- Thirst remains absent.
