# Midnight City V30 — Player Mode Prototype

Run `START_MIDNIGHT_CITY.bat`.

You play as Kirill. Alice remains autonomous.

Controls:
- WASD / Arrow keys — move Kirill
- Walk near Alice — the world pauses and the interaction menu opens
- Interaction menu — choose an action or X/Cancel
- Time controls — normal 1x/2x/4x/8x/16x and AI mode remain available
- Fast-forward — +1h / +6h / +1d / +7d / +30d

This is the first browser prototype of the player-in-the-world architecture. The next step can add free-text conversation after the interaction menu works reliably.
